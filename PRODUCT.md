# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Postwright helps a person create on-brand social posts from templates, verify factual claims, plan publication, and export artwork and captions.

## Users
The repository describes a local marketing studio for one person. The intended audience beyond this is not specified.

## Capabilities and Constraints
Nine templates (a post can have up to 20 slides, each with its own template), ten supported formats, a fact bank with sources, reusable snippets, brand checks, a publication planner, and image/PDF/ZIP export. Plain browser ES modules and CSS, with a Node TypeScript server. No automatic publishing, accounts, or team features. AI writing assistance can run with sample answers.

## Evidence on Hand
README.md, src/web/brand/brand.json, existing SVG identity assets, and assets/demo.png.

## Design Direction
Warm and quiet: the working studio is described in DESIGN.md. The interface should not imply live data or automatic publication.
